# 그림자가 되어줄게 — I'll Be Your Shadow

폰 하나를 **가로로 둘이 같이 들고** 하는 협동 어드벤처예요. three.js로 만들었어요.

▶ **플레이: [starterpack-master.github.io/shadow-couple](https://starterpack-master.github.io/shadow-couple/)** (폰 브라우저로 열고 가로로 돌려요)

두 사람이 **각자 자기 폰**으로 접속해서 같이 해요.
- **🏮 등불**: 빛을 들고 길을 비춰요. 서 있는 위치, 등불 높이, 내려놓는 자리에 따라 실시간 그림자가 바뀌어요.
- **🌑 그림자**: 빛에 닿으면 흐려져요. 등불이 만들어 준 그림자만 밟고 다녀야 해요.

### 같이 시작하기 (각자 폰)
1. 한 명이 **방 만들기**를 누르고 역할(등불/그림자)과 이름을 정해요. 4자리 코드가 떠요.
2. 다른 한 명이 **코드로 참가하기**에서 그 코드와 이름을 입력해요.
3. 연결되면 방장이 **함께 시작하기**를 눌러요.

별도 게임 서버는 없어요. 두 폰이 WebRTC로 직접 연결되고, 처음 만날 때만 PeerJS의 공개 무료 중계를 써요. 연결이 끊기면 같은 코드로 자동으로 다시 붙어요. 폰 하나로 둘이 같이 하는 **한 폰 모드**도 그대로 있어요.

## 실행

```bash
npm install
npm run dev      # 같은 와이파이의 폰에서 http://<PC-IP>:5173 접속
npm run build    # dist/index.html 한 파일(JS/CSS 전부 포함)
```

`dist/index.html`은 파일 하나로 동작해요. Netlify Drop, GitHub Pages, Vercel 같은 정적 호스팅에 올리면 폰으로 바로 할 수 있어요. 폰트는 Google Fonts에서 불러오고, 오프라인이면 시스템 폰트로 대신 보여요.

## 조작

| | 🏮 등불 | 🌑 그림자 |
|---|---|---|
| 이동 | 화면 드래그 (플로팅 조이스틱) | 화면 드래그 |
| 버튼 | ⇅ 등불 높이 (멀리 비추기 ↔ 긴 그림자) · ✋ 등불 놓기/줍기 | » 대시 (짧은 무적, 빛 가로지르기) |
| ♥ | 상대 화면에도 하트가 떠요 | 〃 |
| PC | `WASD`/방향키, `Q` 높이, `E` 놓기, `H` 하트 | 방향키/`WASD`, `/` 대시, `H` 하트 |

한 폰 모드에서는 왼쪽 절반이 등불, 오른쪽 절반이 그림자예요.

대화는 탭하거나 `Space`로 넘겨요. 가운데 ❚❚ 메뉴에는 힌트, 방 다시 시작, 방 건너뛰기가 있어요.

## 구성
- 5챕터 15개 방, 약 1시간
- 추억 폴라로이드 5장, 커플 문답 4개(엔딩에서 궁합 결과), 손잡기 연출, 반전 엔딩
- 기믹: 철창, 달 발판/해 발판, 해바라기, 상자와 구멍, 회전목마, 범퍼카, 등불 걸이, 번개, "잊음"(적), 회전 탐조등
- 에셋 파일 없이 모두 코드로 만들었어요: 텍스처는 캔버스, 음악과 효과음은 WebAudio 생성, 사진은 SVG
- 그림자 판정: 화면의 그림자와 같은 형태를 박스(OBB) 선분 교차로 계산해요 (`src/shadow.js`)

## 코드 구조
```
src/
  game.js      게임 흐름, 방장 판정 + 상태 동기화, 연출 동기화, 카메라, 빛/그림자 판정, 엔딩
  room.js      ASCII 맵 → 지형 메시 + 오브젝트 + 배경
  levels.js    15개 방 데이터 (맵 범례는 파일 상단 주석)
  entities.js  등불, 그림자, 상자, 문, 발판, 해바라기, 회전목마, 잊음 등
  story.js     대본 (이름과 조사를 자동으로 처리해요)
  net.js       PeerJS 연결 (방 코드, 재접속)
  ui.js / photos.js / audio.js / fx.js / models.js / materials.js / input.js / ending.js / emotes.js
tools/         레벨 연결성 검사(validate.mjs), 헤드리스 테스트/스크린샷
```

개발용 URL 옵션: `?room=3-1&go` (해당 방에서 바로 시작), `?auto` (대사 자동 넘김), `?low` (저사양 모드)
